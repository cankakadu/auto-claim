TicketBot fuer Minecraft 1.21.11 (Fabric)

JAR ONLINE BAUEN (ohne Java/Gradle):
1. Auf github.com ein neues, leeres Repository erstellen.
2. "uploading an existing file" waehlen und ALLE Dateien/Ordner dieses Projekts
   hochziehen (auch den versteckten Ordner .github). Commit.
3. Tab "Actions" -> Workflow "Build" laeuft automatisch (ca. 3-5 Min).
4. Fertigen Lauf anklicken -> unten "Artifacts" -> ticketbot-jar herunterladen,
   entpacken -> ticketbot-1.0.0.jar.
5. JAR in den Mods-Bereich des Profils ziehen (kein Modpack-Import!).
   Fabric API muss im Profil installiert sein.

BENUTZEN:
K = Bot an/aus (Menue muss offen sein)
J = listet alle gefundenen Buttons im Chat (zur Fehlersuche / Claim-Text finden)
